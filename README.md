# Paranaque Palengke — Vendor

Vendor portal for stall orders, stock, chat, and store profile.

## Setup

```bash
npm install
cp .env.local.example .env.local   # or reuse VITE_API_URL=http://localhost:1337/api
npm run dev
```

Runs on [http://localhost:5174](http://localhost:5174).

Uses the same Strapi backend as the customerfront and LGU apps.
